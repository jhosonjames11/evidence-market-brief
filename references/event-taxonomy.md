# 事件分类、材料性与去重

## 事件类型

| 类别 | 可视为实质新增的例子 | 常见非实质线索 |
| --- | --- | --- |
| 监管与法律 | 原始监管文件、正式审批/执法/诉讼状态变化 | 对现有规则的评论或猜测 |
| 公司披露 | 财报、指引、法定文件、正式融资/并购公告 | 媒体对旧披露的再解读 |
| ETF 与市场结构 | 发行方/交易所的正式状态、规则或产品变化 | 未核验的流量截图或传言 |
| 协议与安全 | 官方披露的升级、漏洞、暂停、治理结果或可验证链上状态 | 单一社媒帖、未经确认的“攻击”传闻 |
| 宏观与流动性 | 已发布的官方数据或政策决定 | 标题党式市场情绪总结 |
| 经营与技术 | 可验证的产品、供应、合作或里程碑变化 | 重复的发布会评论或营销素材 |

材料性是研究判断，不是价格预测。优先关注是否改变权利义务、现金流/经营假设、准入规则、流动性、系统安全或可验证状态。

## 事件身份与指纹

为每个候选生成：

```text
实体或主题 | 事件类型 | 首次确认时间（含时区） | 核心事实摘要
```

将这一指纹与最近一次已投递报告比对。媒体的发布日期不能替代“首次确认时间”。若只知道报道时间，应明确标记为“首次可见时间，事件时间待核实”，并不得将其视为新增事实。

## 同一事件的处理

以下情况通常视作重复并排除：

- 多家媒体转载同一公告或通讯社稿件；
- 同一新闻的评论、价格复述、观点延伸或标题改写；
- 原事件早于上轮边界、但 RSS 或搜索索引刚更新；
- 无新增事实的“市场正在关注”报道。

以下情况可标为 `新进展`：

- 新的一级来源确认或更正核心事实；
- 已确认风险的范围、金额、受影响实体或官方处置发生实质变化；
- 交易所、监管者、公司或协议采取可核验的新行动；
- 已有事件后出现新的财务、治理、链上或安全状态变化。

重报时要指向先前事件指纹，并明确“此前已知”与“本次新增”的差异。

## 排除与静默

不能核验、无材料性或重复的线索应记录最小的排除理由，但不要扩写成报告主体。没有合格事件并非失败：根据宿主要求输出 `[SILENT]` 或“无重大新增”。网页/工具运行失败是失败状态，必须与“没有新闻”区分开。
